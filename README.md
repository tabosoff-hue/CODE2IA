# CODE2IA 🚀

> Create your own applications with AI — without needing to be an expert in coding.

**CODE2IA** is an AI-powered application creation tool designed to make app development easier and more accessible.

Instead of starting from an empty project, CODE2IA helps you generate and organize application projects using AI.

## ✨ Features

* 🤖 AI-assisted application generation
* 🎨 Modern and customizable interface
* 📁 Automatic project generation
* 🧩 Ready-to-use project structure
* 💻 Python-based
* 🚀 Simple workflow for creating applications
* 🔧 Designed to be extended with new AI features

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/tabosoff-hue/CODE2IA.git
```

Enter the project:

```bash
cd CODE2IA
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\activate
```

Install the dependencies if a `requirements.txt` file is provided:

```bash
pip install -r requirements.txt
```

Run CODE2IA:

```bash
python main.py
```

## 🎨 Vision

CODE2IA aims to make creating applications as simple as possible.

The goal is to allow users to describe what they want and let CODE2IA handle as much of the project creation process as possible.
